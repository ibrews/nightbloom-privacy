# nightbloom-privacy

Public hosting for the privacy policy of **Nightbloom**, procedural AR fireworks for iPhone by
Alex Coulombe Presents. Served via GitHub Pages so App Store Connect and TestFlight can link to a stable,
rendered privacy URL without exposing the (private) app source repo.

The live privacy page: **https://ibrews.github.io/nightbloom-privacy/privacy/**

## Things to Try

1. **View the rendered privacy policy** — open https://ibrews.github.io/nightbloom-privacy/privacy/ in a browser.
2. **Confirm the no-trailing-slash form works** — visit https://ibrews.github.io/nightbloom-privacy/privacy and verify it lands on the same page.
3. **Edit the policy** — change `privacy.md`, update its "Last updated" date, push to `main`, and watch the Pages build republish within about a minute.
4. **Add a support page** — create `support.md` with `permalink: /support/` front matter and link it from `index.md`.
